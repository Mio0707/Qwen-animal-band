# Static Classroom Contract

导出阶段冻结 Song、Preparation、Verified Score、Lesson Recipe、Readiness、Melody Trace、Measure Alignment、Listening Body Plan、四轨 Event Pack、Sticker Arrangement、Gesture Library、Solfege Library 与 Rhythm Runtime Config。

课堂仅通过 `/offline/session.json` 读取快照，并使用 Web Audio API 播放 Event JSON 与内置 Sampler。课堂阶段不调用 Qwen、Local CLI、Python Server、Engine 或 FluidSynth。
